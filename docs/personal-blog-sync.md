# 개인 블로그 동기화

공개된 개인 네이버 블로그 `kjp9204`의 글을 정적 홈페이지로 옮긴다.
Hand 팀 글과 미공개 로컬 문서, 댓글, 프로필 데이터는 동기화 대상이 아니다.

## 2026-09-07 반영 범위

- 기존 GitHub 갱신: 2026-08-06 (기준 커밋 `50d87bf`).
- 이후 공개된 글 21편(2026-08-09~2026-09-07)을 RSS와 공개 글 목록으로 대조했다.
- 기존 개인 글 11편은 보존하여 개인 아카이브는 총 32편이다.
- 이는 해당 기간의 신규 글 동기화이며, 블로그의 모든 과거 글을 이관했다는 의미가 아니다.
- 원문의 문장·표·사진 순서를 보존했다. 네이버 갤러리 조작 버튼과 추적 스크립트는 제외했다.
- 네이버 및 외부 전용 영상은 원문 재생 링크로 제공한다. 내려받을 수 없는 외부 이미지는 명시적인 원문 확인 링크로 표시한다.
- 게시글의 주장·일정·가격을 새로 작성하거나 사실 검증한 작업은 아니다.

## 재실행

Python 3와 `scripts/requirements-sync.txt`의 의존성을 준비한다.
원본 응답 캐시는 저장소 밖의 임시 경로를 사용한다.

```powershell
python scripts/import_naver_posts.py --since YYYY-MM-DD --cache <외부_캐시_경로>
python generate_blog_indexes.py --personal-only
python scripts/verify_personal_sync.py --cache <외부_캐시_경로> --update-sitemap
```

RSS는 최근 50편까지만 제공하므로, 신규 글이 50편 이상인 기간에는 공개 글 목록을 별도로 대조해야 한다.
동기화 전에 기준 커밋과 기간을 확인하고, 실행 후 `data/naver-posts.json` 및 변경 파일을 검토한다.
GitHub 게시 전 원문 대조·로컬 링크·이미지·메타데이터 검사와 화면 확인을 수행한다.
스크립트는 Git 커밋이나 업로드를 자동으로 수행하지 않는다.
